# Executive Sales Performance Dashboard

## Overview
This dashboard analyzes executive sales performance using Power BI.

## Tools
- Power BI
- Power Query
- DAX

## KPIs
- Revenue
- Profit
- Units Sold
- Profit Margin

## Dashboard Features
- Revenue by Region
- Revenue by Category
- Monthly Revenue Trend
- Customer Segment Analysis
- Interactive Filters

## Business Insights
- East region generated the highest revenue.
- Technology was the top-performing category.
- Furniture generated the highest profit.
- Consumer segment contributed the largest share of revenue.
- Revenue peaked in July.
